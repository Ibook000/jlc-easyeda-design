# 演示媒体说明

案例：语音快捷键盘电路，2026-10-21 工程快照。

- `design-process.mp4`：45 秒、1920×1080、24 FPS、H.264/AAC。展示器件摆放、原理图、PCB 布局、走线、GND 铺铜、PCB 成品与三维预览。
- `preview.gif`：同一视频的 640 像素宽、8 FPS、5 倍速静音预览。
- `keyboard-pcb.png`：嘉立创EDA当前 PCB 画布截图。
- `keyboard-3d.png`：客户端真实 3D 预览截图。
- 原理图图片保留在 `../../assets/examples/schematic-keyboard.png`。

原理图、PCB 和三维画面来自项目工程。视频前段依据器件位置、连接和 Gerber 数据制作流程动画，不是历史操作的连续录屏；最后 10 秒为客户端真实 3D 旋转录制。背景音乐为本地合成原创轻音乐。

素材随附记录表明当时最近一次严格 DRC 为 0 错误，这只描述该快照的检查结果。最大电流、制造叠层与 USB 阻抗尚未确定，外部 DFM 未执行；展示视频不能替代整板生产验收。本次 README 更新未修改电路工程。
