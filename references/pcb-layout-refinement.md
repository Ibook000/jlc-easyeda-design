# 布局与线形整理

用于模块下方利用、已有 PCB 整理和程序生成走线后的复核。
这些是布局决策与检查方法，不包含自动布线求解器，也不替代器件参考设计。

## 利用模块下方

- 显示模块的二维封装轮廓不一定是整块禁放区。用户确认下方可用时，结合排针、模块底部器件、
  焊点、支撑柱和插装高度划分可用区域，不把整个轮廓默认排除，也不把所有模块下方默认视为空。
- 优先放低矮阻容、尺寸与高度合适的管理器件；为连接器焊接、工具进入及返修留空间。
- 充电器、稳压器等还要检查散热、模块背板接触与电气绝缘；仅凭截图不能确认高度与温升。
- 不为填满空白而拉长 DC/DC 的开关回路、反馈或去耦回路。
  SW 区、电感与麦克风/模拟电路按各自资料和回流需求分开安排。
- 模块天线净空、拾音孔、传感器开口、安装孔及实际禁止布线区域继续生效。
- 3D 预览用于检查有模型的对象；模型缺失或失真时记录待确认，不能把预览无碰撞称为实物验证。

## 焊盘出线与单一路径

- 尽量从焊盘中心开始出线，再向目标方向扇出。自定义多边形焊盘先核实实际铜形，
  其原点或包围盒中心可能不在铜上；此时选择铜内合适的连接点，避开拾音孔、开槽与其他网络。
- 减少斜擦焊盘边缘、焊盘外的细长颈缩和短小折返。不要为了形式上的中心出线而切过相邻焊盘。
- 对同一连接选合适线宽或铜区，不用两条几乎平行的重复线代替加粗。
  合法的多负载分支、差分线与经计算的并联电流路径不能当作重复线删除。
- 电源加粗需要检查焊盘出口和过孔瓶颈；不能仅凭主干变宽声称载流满足要求。

## 45° 转角与台阶清理

- 默认采用长直段与 45° 转角，避免 90° 直角折弯。用户明确要求不走 90° 时，将其作为本工程约束，
  检查已生成的实际路径；更改布线工具的角度选项不会修复已有直角。
- 栅格寻路可产生“短横线—斜线—短横线”反复交替的台阶。去掉无意义短段，
  合并共线段，把可达的整段整理为直线或少量 45° 折线。
- 不把每个程序分段的接点当成需要强化的焊点。检查自动生成的泪滴，
  清除长线中周期性鼓包或重复泪滴；有需要的焊盘/过孔泪滴仍按实际铜形与间距核验。
- 平行走线保持稳定间距、清楚的通道与自然扇出；不要以无依据的等长或装饰性绕线制造折返。
- 转角整理不能靠降低全板间距、随意变细关键电源线或增加无必要过孔实现。
- 两条单独生成的路径在接点处仍可能组成 90° 折弯，尤其是电源细引脚出口接宽主干的位置。
  除了检查每条路径内部的转角，还要按实际端点拼接同网络、同层的线段检查；
  保留不同线宽的连接关系。识别焊盘入口、过孔换层与多分支接点，避免把它们误当成普通两段折弯。

## 整理时保留真实连接

1. 记录当前工程、组件位置、焊盘网络、板框、禁布区和可恢复快照。
2. 找出分支、过孔、焊盘入口和不同线宽的连接点，作为路径修改的连接约束。
   分支末端可能接在宽线边缘，并不一定落在中心线上。
3. 每个候选短接路径检查完整焊盘铜形、其他网络铜线、孔、板边和所有相关层的禁布区。
   只检查新走线之间的距离，发现不了移动后已有焊盘之间的短路。
4. 修改后从 EDA 读回实际图元，复核网络物理连通性；不能把网络名相同当作已连接，
   也不能因求解器成功就跳过原生 DRC。
5. 重建 GND 铺铜，检查地焊盘、裸露焊盘和过孔。小焊盘热焊盘辐条无法接通时，
   优先调整布局或补短回流连接；选择直接连接时同时考虑焊接与散热。
   布局时就为这些焊盘保留到连续地铜的短路径或邻近过孔空间，避免信号布完后把地焊盘围住。
   离线栅格求解显示无路时，先区分实际铜间距不足与栅格采样过粗；
   必要时局部提高采样精度，再用原始几何及 EDA DRC 复核，不能直接放宽安全间距。
6. 修完铜层后再检查实际顶/底丝印与导出图。普通查看比例判断整体通道，局部放大检查
   台阶、细颈、泪滴、转角及焊盘入口。

## API 与验收记录

- 写源码时软件可能重排记录、舍入坐标、合并或分裂线段；不能只比较图元数量。
  核对关键属性、实际铜形和连接，使用符合软件精度的误差范围。
- 实际设计规则要经当前版本支持的规则入口写入并读回。若源码显示的新规则与 DRC 报告不同，
  先查生效规则、匹配对象和缓存，不通过扩大容差或忽略错误来消除报告。
- 检查顺序为规则与关键布局、信号/电源路径、重建铺铜、实际 DRC/飞线、
  丝印及制造导出。临时无地线的中间状态不能称为全板完成。
- 将通用方法写进 Skill，将项目的模块高度、叠层、充电电流与具体坐标保留在工程记录中。
  不把单次工程的局部例外或未经确认的制造条件升级为通用规则。
