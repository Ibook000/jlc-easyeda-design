# 分阶段验收与证据

## 原理图

- 器件型号、符号/封装引脚映射和位号唯一性已经核实。
- 电源、地、去耦、上下拉、启动、晶振、接口和 NC/EP 已按资料审查。
- 读取实际网表对照目标连接表，检查遗漏、错网、电压域及短接。
- ERC 已执行，错误为零，剩余警告逐条说明；无法执行则记录未执行。
- 原理图模块、文字和连线可读，未靠全部改 BI 或忽略规则掩盖问题。
- 图纸规格、方向及页数已实际设置并核实；允许多张 A4、A3、A2 等适合的组合，内容不挤压、不越图框、不压标题栏。
- 多页标题、页码和全工程唯一位号正确，跨页端口/全局网络经实际网表及全工程 ERC 验证；导出/打印预览逐页无裁切且可读。

## PCB

- 读取实际规则与期望比较，列出默认、网络类、局部例外及其作用对象。
- 符号引脚、焊盘网络和 BOM 版本一致；ECO 变更无未审查项。
- 板框、安装孔、接口、外壳、禁布区和关键布局符合约束。
- 关键网络、电源载流、过孔瓶颈、阻抗/长度及热要求有相应依据；未算不写已算。
- 铺铜重建且绑定正确网络，地连续，关键回流不跨缝，无无意义孤岛。
- 无实际未连接飞线，DRC 零错误，警告有解释，不通过关闭检查掩盖违规。
- 做过线形整理时，确认长线没有周期性小台阶、重复并线或线段接点膨大；
  用户要求无 90° 转角时检查实际铜层的转角，不能只把布线偏好设为 45°。
- 模块下方放器件时，分别记录平面空间和高度/装配证据；没有实物尺寸或可靠模型时将高度核验列为待确认。

## 器件值丝印

对每个在范围内的电气器件检查：

| 检查 | 证据 |
| --- | --- |
| 数据源 | 当前装配版本、原始值/单位/型号、位号和器件 ID |
| 内容 | 实际丝印可见位号和值，DNP 有明确标识，旧值与重复文本已清除 |
| 所在面 | 和器件安装面一致的实际顶/底丝印，不是装配/文档层 |
| 更新 | 移动/翻面/换值/ECO 后读回关联，第二次运行不新增重复标注 |
| 几何 | 字符、字号、笔画、开窗/板边/孔/器件外形及其他文字的实际间距 |
| 制造输出 | 从实际 Gerber 顶/底丝印层看见全部需要的文本，底面视角正确 |

需要覆盖统计时运行 `silkscreen_values.py audit`，但它只核对规范化清单，
不判断字体实际尺寸、几何碰撞或 Gerber 中是否保留。规范化清单必须来自实际 EDA 重读，
禁止把期望计划复制成“重读结果”。

## 最终制造检查

- 打开实际导出的 Gerber 检查层、板框、钻孔、开槽、阻焊和丝印。
- 运行 JLCDFM 或等效制造检查，核实实际下单工艺与规则一致。
- 区分 PCB 铜层 DRC、ERC、DFM 和逻辑功能审查，任何单项不等于整板正确。
- 未运行导出/DFM 时明确写“未执行”，不要为了宣称完成虚构结果。

## 报告形式

仅报告与任务相关的内容：

1. 修改了什么，作用于哪个工程/图页。
2. 规则实际应用值和关键假设。
3. 真实执行的 ERC/DRC/网表/丝印覆盖/几何/Gerber/DFM 结果。
4. 未验证项、具体未满足的器件/网络和下一步。

没有 EDA 连接时称为“方案/离线审查完成”，不能称为“已布好板”。
只加丝印时确认电气网络/铜层未改变，不追加无关全板设计或声称电气审核通过。
