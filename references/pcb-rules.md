# PCB 布局、布线与制造规则

## 参数设置

将下列值视为普通低压 FR-4、1 oz 板的保守起点，使用前核实实际制造选项。
它们不是板厂最新工艺保证或自动计算结果。

| 项目 | 常规默认 | 经核实的局部例外 |
| --- | --- | --- |
| 普通信号线宽 | 0.20 mm | 0.15 mm |
| 普通铜安全间距 | 0.20 mm | 0.15 mm |
| 过孔外径/钻孔 | 0.60/0.30 mm | 0.50/0.25 mm |
| 铜到板边 | 0.50 mm | 0.30 mm，须满足实际工艺 |
| 铺铜间距 | 0.25 mm | 0.20 mm，须满足对应网络类 |
| 电源主干 | 0.50 mm 起始候选 | 以电流/铜厚/温升计算为准 |

- 在专业版“设计 → 设计规则”或当前 API 对应入口设置；标准版菜单按版本另查。
- 开启可用的实时 DRC、规则约束布线/过孔、板边和铺铜间距检查。
- 网络类至少区分普通信号、电源、关键接口；按需要增加模拟、差分、高压等类。
- 区分默认/首选线宽和 DRC 最小值。常规类默认最小值保持 0.20 mm；
  确需 0.15 mm 扇出时用有理由的局部规则/网络类例外，不全板放宽。
- 优先级必须反映在真实项目规则中；记录匹配对象、优先级、参数和读回值。
- 2 oz 或更厚铜、特殊孔、阻抗、填孔等按实际工艺重新定义，不套固定极限表。
- 不默认使用 0.10 mm 全板布线或 0.35/0.20 mm 密集过孔。
- 没有叠层和阻抗目标时，不猜差分线宽线距；可以继续不依赖该参数的工作。

## 布局

1. 固定机械：板框闭合、外壳、安装孔、禁布区、连接器插拔空间、天线净空。
2. 固定关键器件：主控、PMIC/DC-DC、晶振、PHY、ADC、功率器件及接口。
3. 按功能和信号流分区，噪声源远离模拟、基准和晶振；分区不等于随意割地。
4. 去耦靠近对应电源脚，减小供电与接地回路电感；不要把“先到电容”机械变成细长串接。
5. DC/DC 按数据手册压缩关键高 di/dt 回路，限制 SW 铜面积，反馈从正确采样点返回。
6. 晶振与负载电容靠近芯片，减少干扰与过孔；负载值依资料与寄生参数确定。
7. ESD 靠近接口，放电路径短；屏蔽地/机壳地按接口策略连接。
8. 检查散热铜、裸露焊盘、热过孔、焊接可达性和器件返修空间。
9. 为位号和值丝印预留空间；不为文字美观破坏电气布局。

涉及模块覆盖区或走线整理时，继续读取 [布局与线形整理](pcb-layout-refinement.md)。
其中包括模块下方利用、焊盘中心出线、45° 转角、去除台阶与多余泪滴，以及整理后的物理连接复核。

## 地与铺铜

- 四层及以上优先使用完整内层 GND；双层至少一面尽量保持连续 GND。
- 混合信号优先完整地加布局分区；只有数据手册/系统策略明确需要时才分割地。
- 铺铜绑定实际 GND 网络并默认清除无意义孤岛，检查铜区优先级和孤立小块。
- 检查所有关键回流路径，不用“已铺满绿色”代替连通性判断。
- 去耦接地路径短宽，必要时设置邻近地过孔；信号换层考虑相邻回流过孔。
- 不把底层割成细长缝、窄颈、浮铜；不让高速线跨地缝或隔离边界。
- 不在模块天线 keepout 铺铜/放器件/走线；按模块资料核实所有层的净空范围。
- 铺铜不得侵入高压隔离、安装孔机械净空等区域。
- 每次相关布局、走线、过孔或规则修改后重建铺铜，再跑 DRC 和飞线检查。

## 分类型布线

| 类别 | 执行要求 |
| --- | --- |
| 大电流 | 按电流、铜厚、内外层、温升计算，检查连接器、焊盘出口、过孔、保险丝和颈缩 |
| 高速/时钟 | 连续参考面、短路径、减少分支与过孔、换层回流，避免长距离平行串扰 |
| 差分 | 按接口和叠层算阻抗；控制耦合、扇出、过孔一致性、支路及适用长度差 |
| USB | 按实际速率/接口要求；常见 90 Ω 目标不等于所有叠层都用同一线宽 |
| 模拟/基准 | 安静区域、短反馈、正确 Kelvin 采样、避开 SW/PWM/数字边沿 |
| 晶振 | 按资料最短回路，远离噪声；不要为追求视觉等长绕线 |
| RF/天线 | 使用模块/射频参考设计、阻抗与净空要求，不让通用铺地规则覆盖 RF 约束 |
| 高压/隔离 | 按适用标准、工作/瞬态电压、污染等级、材料组、海拔等计算间隙与爬电 |

不要把某个固定电压以下视为绝对安全，或把 0.20 mm 间距推广到全部低压系统。
自动布线只处理低速非关键网络，预先确认板框、封装、网络和既有 DRC。
完成后人工/可视化检查绕线、过孔、回流、关键网和地连接。

## 完成条件

重建铺铜、无实际未连接网络、DRC 零错误、逐条解释警告；
检查所有适用专项、电源瓶颈、丝印和机械约束，再导出 Gerber 做 DFM/目视复核。
DRC 通过不证明阻抗、逻辑连接、电流或散热都合格；未做的检查标为未执行。
